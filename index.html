About

Embedded systems enthusiast and active STM32 application developer.

Over the years, I have written many small, dependency-free C libraries for microcontrollers: parsers, buffers, memory managers and protocol stacks that are easy to use and fit on devices with only a few kilobytes of RAM.

Several of these open-source projects, along with others I've contributed to, are listed below.

Projects

Other things I have built or contributed to.

  • C coding style

    Recommended C code style and coding rules for C99 or later. Comes with an AI agent skill to write, edit and format code.

  • STM32F4-Discovery.net

    Tutorials and libraries for STM32 microcontrollers.

  • STM32 UART & DMA

    STM32 UART examples using DMA for efficient receive and transmit when the received data length is unknown.

  • Arm CMake build kit

    CMake build kit for Arm Cortex-M projects with simple configuration.

  • STM32 CMake

    Tutorial explaining the STM32 development flow in Visual Studio Code with CMake and the Cortex-Debug extension.

  • Addressable LEDs

    WS2812 and similar addressable LEDs driven by an STM32 timer and DMA, offloading the CPU.

    CANopen stack port for STM32: initial setup and active contributor.
